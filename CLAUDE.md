# Design System

Typography:
- Use Inter
- Maximum 5 font sizes
- Strong hierarchy
- Avoid oversized text

Spacing:
- Strict 8px spacing grid
- Large section breathing room
- Consistent card padding

Motion:
- Framer Motion only
- Subtle animations
- No bounce animations
- No animation spam
- Use opacity + translateY transitions

Colors:
- Dark neutral backgrounds
- Minimal accent colors
- High contrast text
- Avoid random gradients

Components:
- Rounded corners max 16px
- Consistent shadows
- Minimal borders
- Clean cards

Avoid:
- floating blobs
- neon cyberpunk
- excessive glassmorphism
- generic AI aesthetic
- decorative clutter
